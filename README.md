# Employee Management System

Enterprise-grade Angular SPA skeleton using Angular 21 standalone components, Signals, RxJS, Bootstrap 5, lazy routes, functional guards/interceptors, RBAC, mock APIs, and strict TypeScript.

## Runtime

Angular `21.2.13` requires Node `^20.19.0`, `^22.12.0`, or `>=24.0.0`.

This machine currently reports Node `22.3.0`, so install/build commands require a Node upgrade.

## Demo Credentials

- Admin: `admin@ems.local` / `Admin@123`
- Employee: `employee@ems.local` / `Employee@123`

## Commands

```bash
npm install
npm start
npm test
npm run build
```
