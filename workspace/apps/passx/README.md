# PassX

Premium, Apple-inspired password generator. Built with React 19, Vite, TanStack Start, Tailwind v4, shadcn/ui, Framer Motion, and Zustand.

See `INSTRUCTIONS.md` for setup. See `PACKAGES.txt` for the dependency list.

Quick start:
```bash
bun install && bun dev
# open http://localhost:8080
```
