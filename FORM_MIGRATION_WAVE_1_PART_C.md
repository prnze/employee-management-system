## 2. Accessibility Verification

* **Label-to-Control Association**: Handled via dynamic template reference variable binding. For instance:
  ```html
  <app-form-field #orgField label="SETTINGS_ORG_NAME">
    <app-input [id]="orgField.id" ...></app-input>
  </app-form-field>
  ```
  This links the `<label [attr.for]="id">` generated by `FormFieldComponent` to the actual native `<input [id]="id">` inside `InputComponent`, ensuring 100% compliant screen-reader accessibility.
* **Keyboard Navigation**: Input fields support full tabbing, focus states, and standard native controls.
* **Aria Attributes**: Generated unique IDs are bound correctly to inputs.
